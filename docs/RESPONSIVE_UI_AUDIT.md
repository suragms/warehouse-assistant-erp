## Existing shared foundation and verification

`frontend/src/main.tsx` loads `theme/globals.css` and AppRouter, not template App.tsx. Template `App.css`/`index.css` remnants therefore are not evidence of active layout bugs. `layouts/AppShell.tsx` has a desktop sidebar at md, min-w-0 content and scrollable main; `MobileNavigation.tsx`, `useMobileViewport.ts`, CSS safe-area/dvh insets and mobile feedback styles form a working mobile shell. The More menu implements keyboard/focus behavior that the generic Modal does not. `AuthProvider.tsx` clears query cache and remounts routed children when user/tenant/role/permissions change; preserve that isolation.

Executed: frontend tests 127 passed, lint and production build succeeded. Selected Edge Playwright suites (`barcode-tools`, `csv-exports`, `desktop-navigation`, `mobile-navigation`) passed 56/56. They mock API/auth/provider responses, not a real PostgreSQL application session. Tested widths include barcode 390/768/1440, mobile 390/393/412, desktop 1366/1440/1920 and constrained 320x360 shell. Mock navigation fixture has Owner/Manager/Staff/SuperAdmin but **no Admin type**. Most route content is short/empty; broad empty/loading/error/long-data coverage is absent.

Visually inspected generated `frontend/test-results/mobile-navigation-mobile-navigation-Owner-390x844/more.png` and `barcode-tools-barcode-labels-and-manual-fallback-at-390px/printed-label.png`. These show contained scrollable More chrome and isolated printable label. This is not an all-page visual certification. Those ignored test artifacts may be replaced by later test runs.
